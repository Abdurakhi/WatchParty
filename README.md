# WatchParty

Open-source watch party platform for synchronized video watching.

## Overview

WatchParty is a real-time collaborative video watching platform.

Main goal:

- synchronized video playback;
- virtual browser sessions;
- voice communication;
- real-time rooms;
- cross-platform support.

## Features

### Core

- Create rooms
- Join rooms
- Video synchronization
- Real-time chat
- Voice communication

### Supported sources

Planned:

- Google Drive
- VK Video
- Direct video sources
- Virtual browser sessions


## Architecture

The project uses:

- Backend API
- Frontend PWA
- Browser streaming service
- WebRTC communication
- Docker infrastructure


## Repository structure

- backend/ Backend API
- frontend/ Web application
- browser-service/ Virtual browser system
- infrastructure/ Infrastructure configs
